# 2026-09-21 — rdap.kr 애드센스 지적사항 조치

## 무엇이 문제였나

애드센스가 rdap.kr을 **"게시자 콘텐츠가 없는 화면"**과 **"가치가 낮은 콘텐츠"**로 지적했다.
원인은 둘이었다.

1. **조회 도구 화면에 광고가 붙어 있었다.** `rdap-javascript-ko.html` / `-en.html` 은
   입력창·조회 버튼·결과 자리뿐이고 읽을 글이 없다. 구글은 이런 순수 도구 화면에
   광고를 붙이는 것을 명시적으로 금지한다.
2. **사이트에 화면이 넷뿐이었다.** 소개(한/영) + 도구(한/영). 사이트 전체 분량으로
   보면 심사를 통과하기에 너무 적었고, 개인정보처리방침·이용약관도 없었다.

## 무엇을 했나

### 1. 도구 화면에서 광고 떼기

`rdap-javascript-ko.html` · `rdap-javascript-en.html` 의 애드센스 스크립트 제거.
자리에 **왜 떼었는지와 언제 되살릴 수 있는지**를 적은 주석을 남겼다 — 이 화면에
읽을 글을 충분히 채우기 전에는 다시 붙이지 않는다.

광고가 남는 곳: 소개 · 결과 읽는 법 · 자주 묻는 질문 · 이용약관 · 개인정보처리방침.
관리자 통계 화면(`bootstrap_server/rdap-dashboard*.html`)은 이전과 같이 광고 없음.

### 2. 글 화면 여덟 장 신설 (4장 × 한/영)

| 파일 | 내용 |
|---|---|
| `rdap-guide-ko.html` / `-en.html` | RDAP 조회 결과 읽는 법 — 응답 뼈대, status 값 사전 12종, events, entities·vcardArray, secureDNS, IP/ASN 필드, 가려진 정보(redaction), 오류 코드 |
| `rdap-faq-ko.html` / `-en.html` | 자주 묻는 질문 15문항 |
| `rdap-terms-ko.html` / `-en.html` | 이용약관 10개 조항 |
| `rdap-privacy-ko.html` / `-en.html` | 개인정보처리방침 — 수집 항목, 30일 보관, 쿠키·제3자 광고 고지, 이용자 권리 |

개인정보처리방침의 수집 항목은 실제 코드를 읽고 맞췄다:
`traffic_log.py`(접속 시각·IP·국가·도시·경로·응답코드·UA, 30일),
`visit_log.py`(무작위 식별자 `onnamu_vid`, 경로·국가만, **IP 기록 안 함**, 30일).

### 3. 연결과 뼈대

- 탭줄을 2개 → 4개(소개 · 웹 클라이언트 · 결과 읽는 법 · 자주 묻는 질문)로 넓히고
  꼬리말에 약관·개인정보 링크 추가. 기존 4개 화면도 같이 고쳤다.
- 모든 화면에 `canonical` · `hreflang` 추가 — 한/영 판이 서로를 가리킨다.
- `bootstrap_server/main.py` 에 새 화면 8개 + `robots.txt` + `sitemap.xml` 경로 추가.
- `robots.txt` — 관리자 화면(`/dashboard`)·내부 API는 막고 나머지는 연다.
- `sitemap.xml` — 화면 12장 + 뿌리, 언어쌍을 `xhtml:link` 로 묶었다.

### 4. 좁은 화면 탭 깨짐 수정

탭이 넷이 되자 390px 폭에서 글자가 한 자씩 세로로 쌓였다.
`rdap-v3.css` 에 640px 이하 규칙을 더해 줄바꿈을 막고 옆으로 밀어 보게 했다.

## 확인한 것

- 화면 16개 경로 모두 200 응답, 광고 태그는 글 화면에만 있고 도구 화면에는 없음
  (FastAPI TestClient).
- 내부 링크 깨짐 0건 (HTML 12장 전수).
- 1280px · 390px 실제 렌더링 확인.

## 남은 일 (사람이 해야 함)

1. 배포 후 `https://rdap.kr/rdap-privacy-ko.html` 등 새 주소가 실제로 열리는지 확인.
2. 구글 서치 콘솔에 `sitemap.xml` 제출.
3. 애드센스에서 **"문제를 수정했음을 확인합니다"** 누르고 재심사 요청.
