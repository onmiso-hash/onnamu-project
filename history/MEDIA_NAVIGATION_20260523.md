# Media Navigation Improvement (2026-05-23)

## 작업 개요
미디어 홈(Media Home)의 갤러리 뷰어(Lightbox)에 이전/다음 미디어 탐색 기능을 추가하였습니다.

## 주요 변경 사항

### 1. Lightbox UI 개선
- **탐색 버튼 추가**: 좌우측에 이전(`‹`), 다음(`›`) 버튼을 추가하여 클릭으로 미디어를 넘겨볼 수 있게 함.
- **카운터 표시**: 현재 보고 있는 미디어의 순번을 표시 (예: `3 / 10`).
- **애니메이션 효과**: 미디어 전환 시 부드러운 페이드 및 스케일 효과 적용.
- **스크롤 제어**: 라이트박스가 열려 있을 때 배경 스크롤을 방지하여 사용자 경험 개선.

### 2. 다각도 제스처 및 입력 지원
- **좌우 클릭**: 탐색 버튼을 통한 직관적인 조작.
- **키보드 단축키**: 왼쪽/오른쪽 화살표 키로 이전/다음 미디어 탐색, ESC 키로 닫기 지원.
- **스와이프 제스처**: 모바일 환경을 고려하여 좌우 스와이프로 미디어를 넘겨볼 수 있는 기능 구현.

## 대상 파일
- `gallery/templates/gallery.html`

## 향후 계획
- 영화관(Movie Theater) 섹션에도 유사한 전체 화면 탐색 기능 도입 검토.
