# 2026-05-31: Hyper Snake(하이퍼 스네이크) 모던 웹게임 개편

기존의 낡고 정적인 클래식 Snake 게임을 완전히 삭제하고, 극강의 네온 사이버펑크 디자인과 풍부한 아케이드 요소가 결합된 싱글 페이지 웹게임 **'Hyper Snake'**로 개편하였습니다.

## 🛠️ 작업 내용 요약

1. **디자인 테마 현대화**
   - 어두운 밤하늘에 별빛과 격자가 수놓아진 듯한 사이버네틱 백그라운드 디자인을 적용하였습니다.
   - 유리모피즘(Glassmorphism)과 네온 글로우(Neon Glow) 효과를 결합한 게임 대시보드를 구축하였습니다.
   - Google Fonts (`Orbitron`, `Rajdhani`)를 연동하여 SF/사이버펑크 감성의 비주얼 완성도를 높였습니다.

2. **가속도 및 난이도 시스템 구현**
   - 음식을 먹을 때마다 뱀의 속도가 빨라지는 물리 가속도 공식을 탑재하였습니다.
   - 난이도별(Easy/Normal/Hard)로 시작 속도, 음식당 가속 강도, 한계 속도(Speed Limit)를 다르게 설계하여 플레이 편의성을 최적화하였습니다.
   - 상단 상태바에 속도 진행 백분율을 다이내믹 게이지 UI로 시각화하였습니다.

3. **로컬 스토리지 연동 최고 기록 랭킹 보드**
   - 난이도별로 분리 저장되는 `localStorage` 연동 랭킹 시스템을 우측 사이드바에 구현하였습니다.
   - 게임오버 시 5위 이내 순위권 진입 시, 화려한 유리모피즘 모달 팝업을 통해 파일럿 닉네임을 입력받을 수 있습니다.
   - 언제든지 테스트와 초기화가 가능하도록 대시보드 하단에 '모든 기록 초기화' 기능을 배치하였습니다.

4. **생동감 넘치는 애니메이션 & Web Audio API 효과음**
   - **파티클 시스템(Particle System)**: 음식을 먹을 때 스파크 입자가 사방으로 퍼지며, 게임 오버 시 뱀의 마디마디가 폭발하며 흩어지는 대형 이펙트를 구현하였습니다.
   - **화면 진동(Screen Shake)**: 게임오버 또는 벽 충돌 시 캔버스 요소가 격렬하게 흔들리는 타격감을 추가했습니다.
   - **Web Audio API**: 단음/화음 아르페지오 신디사이저 효과음(음식 획득 시 맑은 주파수 스윕, 골든 에너지 코어 획득 시 화음, 폭발 시 노이즈 rumbles)을 라이브로 구현하여 리소스 요청 없이 완벽히 동작합니다.

5. **Games Hub 로비 연동**
   - `/games/templates/index.html` 로비 화면의 카드를 'Hyper Snake'로 개편하고 매혹적인 네온 디자인과 'NEW' 배지를 적용하였습니다.
