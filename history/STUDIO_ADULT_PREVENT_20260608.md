# 🔮 일반 계정 19금 세션 및 프리셋 접근 원천 차단 (2026-06-08)

admin 계정으로 대화 및 19금 설정을 진행하던 브라우저에서 family 등 일반 계정으로 전환해 로그인했을 때, 로컬 스토리지 및 서버 동기화 로직상의 권한 검증 누락으로 인해 이전 19금 세션이 꼬여 복원되거나 유입되는 취약점을 해결했습니다.

---

## 🛠️ 1. 수정 및 보완 내역

### 1) 프론트엔드 세션 보안 필터 강화 (`studio/app.js`)

#### ① 로그인 계정 전환 자동 감지 및 로컬 스토리지 강제 초기화
- `fetchUserInfo()` 완료 시, `/api/user-info`에서 받아온 `username`과 `localStorage`에 기록된 `logged_in_username`을 대조합니다.
- 로그인한 유저명이 달라진 경우(즉, 계정이 admin ↔ family 등으로 전환된 경우), 이전 세션 찌꺼기가 남아 영향을 미치지 못하도록 스튜디오 관련 모든 로컬 스토리지 키(`persona_presets`, `recent_*`, `studio_active_state` 등)를 강제 삭제(Clear) 처리합니다.
- 그 후 현재 유저명을 `logged_in_username`으로 갱신하여 세션 정합성을 상시 유지하도록 보완했습니다.

#### ② 대화 복원(`Restore`) 단계에서의 19금 무단 진입 차단
- 새로고침 등으로 대화 세션을 자동 복구할 때(`activeState === 'active'`), 현재 유저가 일반 계정(`!this.isAdmin`)이라면 이전 세션의 수위가 `adult-19`이거나 19금 프리셋인지 2차로 체크합니다.
- 만약 19금 관련 세션일 경우 복원 기동을 차단하고 `activeState`를 비활성화(`inactive`) 상태로 강제 전환하여 설정창으로 유도하며, 19금 세션 관련 로컬 찌꺼기 설정을 제거합니다.

#### ③ 스튜디오 기동(`startStudio`) 시 설정 최종 검증 및 리셋
- 스튜디오 기동 최종 단계에서 일반 사용자가 19금 장르/수위 설정을 전송하거나 19금 프리셋을 선택하려 한 경우, 2차 방어벽을 작동시킵니다.
- **챗 모드**: 수위 설정이 `adult-19`이거나 캐릭터명이 `릴리스` 또는 `19금` 텍스트를 포함하고 있으면 강제로 전체이용가 기본 캐릭터('서아', 일반 등급)로 리셋 및 강제 전환하고 경고창을 제공합니다.
- **소설 모드**: 장르가 `adult-19`이거나 분위기가 `sensual`인 경우 강제로 전체이용가 기본 설정('fantasy', 'normal')으로 강제 전환합니다.
- 세션 자동 복원 시에도 복원하려는 데이터에 19금 수위나 장르가 포함되어 있으면 복원을 안전하게 생략합니다.

#### ④ 서버 양방향 동기화(`Sync/Push`) 시 19금 유출 필터링
- **`pushPersonasToServer()`**: 일반 계정일 경우, 로컬에 저장되어 있던 19금 프리셋 정보가 서버로 백업되지 않도록 전송 바디에서 완전히 걸러내고 전송합니다.
- **`syncPersonaPresetsWithServer()`**: 서버에서 유저 데이터를 가져올 때(`serverPresets`), 일반 계정이면 19금 수위나 타이틀을 포함한 프리셋을 로컬 병합 목록에서 누락시키며 로컬 스토리지에 저장하지 않습니다.

### 2) 백엔드 이중 안전장치 구축 (`studio/server.js`)

- 프론트엔드 우회 가능성을 원천 차단하기 위해, 영구 보존 API에서도 권한에 따른 데이터 필터링을 탑재했습니다.
- **GET `/api/personas`**: 유저의 프리셋 파일(`data/personas_${username}.json`)을 조회할 때, 현재 요청한 유저가 관리자가 아닌 일반 계정(`!req.user.is_admin`)인 경우, 19금 설정(`level === 'adult-19'` 또는 이름에 `19금`이 들어간 프리셋)을 원천 제외한 깨끗한 JSON만 클라이언트에 반환합니다.
- **POST `/api/personas`**: 클라이언트가 전송한 프리셋 목록 데이터를 저장하기 전에 한번 더 이중으로 일반 계정 여부를 검사하여 19금 프리셋이 있을 시 해당 항목을 완전히 파괴한 후 파일 시스템에 보존합니다.

## 📅 2. 검증 및 결과 보고

- **관리자 계정(admin)**: 기존과 동일하게 '릴리스' 등 19금 캐릭터 생성, 19금 설정 저장 및 대화 진행이 정상적으로 가능함을 확인하였습니다.
- **일반 계정(family)**: 
  - admin이 플레이하던 브라우저에서 로그아웃 후 family 계정으로 로그인 시 로컬 스토리지가 완벽하게 자동 포맷되고 전체이용가 오버레이 화면으로 진입함을 확인했습니다.
  - 임의로 19금 프리셋(릴리스 등)을 로드하거나 URL 우회를 시도해도 스튜디오 시작 단계에서 전체이용가 캐릭터('서아')로 안전하게 자동 리셋 및 강제 보정이 이루어짐을 확인했습니다.
  - 데이터 파일(`data/personas_family.json`)에 19금 설정이 기록되지 않고, 동기화 과정에서도 노출되지 않음을 보장합니다.
