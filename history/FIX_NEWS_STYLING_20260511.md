# 상세 작업 내역: 뉴스 요약 스타일링 개선 (2026-05-11)

## 1. 개요
포털 서비스의 'Daily News Timeline' 모달창에서 뉴스 요약 도입부(브리핑) 스타일이 특정 날짜(5월 11일)에 헤드라인 스타일로 잘못 출력되는 현상을 수정함.

## 2. 문제 원인 및 1차 실패 분석
- **초기 원인**: 특정 문구("요약해 드립니다")에 의존하여 스타일을 결정하여 일관성이 없었음.
- **1차 수정 실패**: 트리거를 `📰 오늘의 주요 뉴스` 로 고정했으나, 실제 데이터베이스에는 `🗞️ 오늘의 주요 뉴스` 처럼 **이모지가 다르게 들어가는 경우**가 존재함.
- 이로 인해 정확한 문자열 매칭이 실패하였고, 코드 로직이 모드를 전환하지 못해(isIntroMode가 계속 true 유지) **전체 뉴스 본문이 도입부 브리핑 스타일(작고 하얀 글씨, 들여쓰기 없음)로 강제 적용되어 레이아웃이 완전히 붕괴됨.**

## 3. 최종 해결 방법 (`portal/app.py` 수정)
- **결정적 마커 우선 처리 (Index-based Match)**: 특정 이모지에 의존하지 않고, 문자열 맨 앞부분(인덱스 5 이하)에 `'오늘의 주요 뉴스'`라는 텍스트가 존재하는지만 검사하여 모드를 강제 전환함.
- **상태 고립 및 CSS 복원**: 모드 전환 전(isIntroMode === true)은 브리핑 스타일을, 전환 후에는 **기존에 잘 작성되어 있던 CSS 클래스(`.news-category`, `.news-title`, `.news-bullet`)**를 그대로 반환하여 들여쓰기 뎁스와 폰트 굵기를 100% 복원함.

## 4. 결과
- 어떤 이모지가 들어가든 '오늘의 주요 뉴스'가 앞에 있으면 정확히 헤더로 인식함.
- 헤더 이전은 차분한 브리핑 스타일로, 헤더와 본문은 크고 명확한 원래의 레이아웃으로 완벽히 정렬되어 출력됨.
