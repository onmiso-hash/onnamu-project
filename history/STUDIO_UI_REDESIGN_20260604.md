- **작성일**: 2026-06-04
- **작성자**: Antigravity (AI)
- **작업 목적**: 2분할 레이아웃이었던 창작 스튜디오 UI를 Google Gemini 스타일의 단일 피드 인터페이스와 좌측 슬라이드 사이드바, 수직 3단 고정 HUD로 대대적으로 통합 및 리팩토링하여 웹/모바일 반응형 경험을 상향시킴.

## 🎨 주요 변경 내용

### 1. 좌측 슬라이드 메뉴 (사이드바) 구성
- 평소에는 접혀 있다가, 상단 헤더 좌측의 **☰ (메뉴 버튼)**을 누르면 부드럽게 왼쪽에서 미끄러지듯 열리는 사이드바 패널(`#studio-sidebar`)을 추가.
- **메뉴 항목 배치**:
  - 🔊 사운드 토글 (`btn-toggle-sound`)
  - 💾 현재 세션 저장 (`btn-save-session`)
  - ↩️ 실행 취소 / 취소 (`btn-undo-story`)
  - 🔄 리셋 / 다시 쓰기 (`btn-reset-story`)
  - ⚙️ 설정 화면(홈)으로 (`btn-home-settings`)
  - 💾 텍스트 다운로드 (`btn-export-text`)
  - 🚪 로그아웃 (`btn-logout`)
- **반응형**: 모바일에서는 화면 전체를 덮는 슬라이드 아웃 패널과 터치 시 자동으로 닫히는 반투명 백드롭 오버레이를 구현하였고, 사용자가 사이드바 내부의 개별 메뉴 아이템을 클릭할 때도 사이드바가 자동으로 접히게 마크업/스크립트 제어.

### 2. 상단 수직 3단 고정 헤더
대화 피드 위에 항상 고정되어 스크롤되지 않는 다단 고정 헤더 영역을 수직 순서로 정렬:
- **1단 (최상단 - 설정 정보)**: 장르, 서사 분위기, 주인공, AI 모델 정보를 일렬로 정렬한 배지 그룹 바. 좌측에 ☰ 메뉴 토글 버튼 배치.
- **2단 (중간 - 캐릭터 정보)**: 캐릭터 이미지(아바타), 캐릭터 이름, 호감도(💖 수치 및 바). *소설 모드에서는 숨김 처리*
- **3단 (하단 - 주요 메모리)**: 화면 영역을 너무 차지하지 않도록 **"🧠 주요 기억 메모리 (클릭하여 확인)"** 형태의 슬라이드 토글 방식으로 설계. 클릭 시 아래로 아코디언처럼 열려 대화 내역 공간을 침범하지 않게 조율. *소설 모드에서는 숨김 처리*

### 3. 중앙 단일 대화 피드 스트림 (`#story-scroll-area`)
- 기존의 좌측 책(Codex) 및 우측 오라클 예언자 로그의 2분할을 **단일 피드**로 일원화.
- `app.js`에서 챗 로그(`chatLogArea`)를 스토리 스크롤 영역(`storyScrollArea`)에 동일하게 통합 바인딩하여 오작동 없는 안전장치 확보.
- **렌더링 방식 최적화**: 실시간 생성 및 답변 수신 단계에서는 `isGenerating` 플래그를 활용하여 캔버스를 싹 지우지 않고 메시지 버블을 순차적으로 덧붙임으로써 번쩍임 제거 및 타이핑 애니메이션 보존. 세션 복구 및 Undo 시에만 캔버스를 초기화하고 처음부터 끝까지 정렬하여 리렌더링.

### 4. 하단 고정 제어 영역 (`#studio-bottom-controls`)
- **추천 선택지 칩**: 가로 스크롤이 매끄럽게 동작하는 칩 카드 형태로 추천 행동 3가지를 배치.
- **Gemini 스타일 텍스트 상자**: 둥근 코너와 글로우 그림자 효과를 입혔으며, 여러 줄 입력 시 `textarea` 높이가 실시간으로 늘어나는 자동 높이 조절 스크립트 바인딩.
