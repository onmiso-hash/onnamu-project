## 1. 영화관 썸네일 ffmpeg 전환 (781f1b1)

**문제**: 영화관 접속 시 동영상 파일을 매번 스트리밍하여 썸네일 로딩 속도가 매우 느림

**수정 파일**:
- `gallery/Dockerfile` — `apt-get install -y ffmpeg` 추가
- `gallery/app.py` — `serve_thumbnail` 엔드포인트 신규 구현
  - 이미지: Pillow로 640×360 JPEG 생성, `/app/.thumbnails/` 캐싱
  - 동영상: `ffmpeg -ss 10 -i input -frames:v 1 -vf scale=640:-2 -q:v 3` 실행, 10초 실패 시 0초로 재시도
- `gallery/templates/movies.html` — `<video>` 태그를 `<img data-src="/thumbnail/...">` 로 교체, IntersectionObserver 기반 lazy loading 적용

**결과**: 최초 생성 후 캐싱으로 이후 즉시 표시

## 2. CLAUDE.md 히트맵 등록 방식 수정 (98a179c)

**문제**: 기존 `sqlite3 portal/data/news.db INSERT` 방식이 동작하지 않음
- 원인: 포털은 Docker named volume (`portal_news_data`) 사용 → 로컬 파일시스템의 DB가 컨테이너 내부 DB와 별개

**수정**: `curl -X POST https://onnamu.kr/api/work/save -H "X-API-Key: $SECRET_KEY"` 방식으로 변경
- `SECRET_KEY`는 `gallery/.env`에서 읽어옴

**문제**: ffmpeg를 포함한 Docker 이미지 첫 빌드 시 10분 기본 타임아웃 초과 가능성

**수정**: `command_timeout: 30m` 추가

## 4. deploy.yml SSH 인증 방식 전환 (bf2cc43)

**문제**: 미니PC SSH 인증 방식을 비밀번호→키 기반으로 변경했으나 deploy.yml이 여전히 `password:` 사용 → GitHub Actions 배포 즉시 실패

**수정**:
- `password: ${{ secrets.PASSWORD }}` → `key: ${{ secrets.SSH_PRIVATE_KEY }}`
- GitHub Secrets에 `SSH_PRIVATE_KEY` 등록 (PuTTYgen으로 PPK → OpenSSH 변환)
- SSH 접속 username: `onmiso` (not `onmis`)
