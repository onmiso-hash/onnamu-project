## 🛠️ 안드레이 카파시 AI 코딩 4원칙 명세

### 1. Think Before Coding (코딩 전 생각)
*   **지침**: 에이전트는 코드 작성 전에 문제 상황을 분석하고 가정을 자의적으로 정의하지 않습니다. 모호한 부분은 항상 질문을 통해 해소하며 분석 및 영향도 검토 완료 후 구현 계획을 사용자에게 먼저 제안하고 승인받습니다.
*   **연관 기존 수칙**: `사전 작업 승인`, `영향도 분석 의무화`

### 2. Simplicity First (단순함 우선)
*   **지침**: 에이전트는 문제를 해결할 수 있는 최소한의 코드로 구현을 제어합니다. 사용자가 명시하지 않은 추가 추상화, 모듈화, 불필요한 기본값 및 편의 설정 덧붙이기를 일절 금지합니다.
*   **연관 기존 수칙**: `자의적 판단 배제`

### 3. Surgical Changes (수술처럼 정밀한 변경)
*   **지침**: 요청받은 특정 기능 및 라인만을 정밀하게 타격하여 수정 범위를 국소화합니다. 주변 코드 스타일, 미관련 주석, 개행 등을 무분별하게 변경하여 불필요한 충돌이나 변경 로그 오염을 방지합니다.
*   **연관 기존 수칙**: `자의적 판단 배제`, `영향도 분석 의무화`

### 4. Goal-Driven Execution (목표 중심 실행)
*   **지침**: 작업의 명확한 성공 완료 기준을 잡고, 기능 배포 및 정상 동작을 자체적으로 끝까지 검증한 후 완료 보고를 올립니다. 섣부른 "완료 선언"을 피하고 "재검증 권유" 형태의 신중한 보고를 견지합니다.
*   **연관 기존 수칙**: `신중한 보고 및 검증 권유`, `원격 배포 의무화`
