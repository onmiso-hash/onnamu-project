# 2026-05-30: 매치-3 퍼즐 게임 'Cloud Crush' 추가 및 포털 연동

## 🎮 게임 개요
- **게임명**: Cloud Crush (클라우드 크러쉬)
- **종류**: 8x8 그리드 매치-3 퍼즐 게임
- **기술**: HTML5 Canvas, 바닐라 자바스크립트(Vanilla JS), CSS Glassmorphism
- **위치**: `/cloud_crush` (게임 마이크로서비스 내 템플릿: `games/templates/cloud_crush.html`)

## 🏗️ 구현 상세

### 1. Flask 라우트 및 로비 연결
- `games/app.py`에 `@app.route('/cloud_crush')` 라우트를 신설하여 게임 화면 템플릿을 서빙하도록 구현.
- `games/templates/index.html` 게임 로비 화면에 'Cloud Crush' 전용 카드 UI 디자인 추가 및 ☁️ 이모지와 함께 연결 완료.

### 2. 비주얼 & 테마 디자인
- **날씨 & 감정 구름 캐릭터**: 5가지 종류의 구름 캐릭터를 Canvas 2D API로 직접 벡터 드로잉 구현.
  - 하늘색 뭉게구름(기쁨), 회색 먹구름(심술), 남색 비구름(슬픔 + 눈물), 주황색 해구름(윙크), 핑크색 바람구름(발그레)으로 귀여운 분위기 연출.
- **Glassmorphism 대시보드 UI**: 투명도 높은 파스텔톤 보더라인과 블러 백그라운드 필터를 조화시켜 세련된 모던 웹 디자인 확보.
- **네온 프로그레스 바**: 스테이지 클리어를 위한 목표 점수 대비 현재 달성도를 네온 그라데이션 게이지 바로 시각화.

### 3. 게임 플레이 메커니즘
- **드래그 & 클릭 선택 스왑**: 마우스 드래그(스와이프) 또는 연속 터치 클릭을 통해 인접 타일을 부드럽게 스왑하고, 유효하지 않은 매치일 시 원래 자리로 복원하는 부드러운 Tween 롤백 적용.
- **4매치/5매치 특수 타일**:
  - 4개 매치 시: 십자 방향 가로/세로 전체를 터뜨리는 **번개 구름 (⚡)** 생성.
  - 5개 매치 시: 스왑한 타일과 같은 모든 컬러를 일괄 폭파하는 **무지개 구름 (🌈)** 생성.
- **가속 중력 낙하 & 리필**: 타일이 터지고 남은 빈자리에 윗 타일들이 속도를 받아 부드럽게 낙하하며, 위에서는 새 타일들이 보충되는 물리 드롭 엔진 구현.
- **연쇄 콤보**: 낙하 완료 후 2차, 3차 연속 매치를 자동 감지하여 콤보 배수 점수 가산 적용.
- **막다른 골목 자동 셔플 (Shuffle)**: 보드 상에 매칭 가능한 경로가 없는 경우, 화면이 몽환적으로 흩어지며 자동 리셔플되어 끊김 없는 플레이 보장.

### 4. Web Audio API 효과음 엔진
- 외부 오디오 리소스 없이 실시간 주파수 합성(Synthesis)을 통해 가볍고 경쾌한 8비트 사운드 탑재.
  - 선택음, 매치 성공음, 콤보 상승음, 번개/무지개 발동음, 스테이지 클리어음, 게임오버 음향 구현.
  - 사이드 패널 내 사운드 FX On/Off 토글 지원.

### 5. 데이터 저장
- 로컬 스토리지(`localStorage`)와 실시간 동기화하여 플레이어가 달성한 최고 스테이지 및 최고 점수를 영구 저장 및 화면 출력.
