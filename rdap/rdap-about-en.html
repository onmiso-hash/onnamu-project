What is RDAP?

RDAP (Registration Data Access Protocol) is a next-generation protocol for querying internet resource registration data (RFC 7480~7484), designed by IETF to replace the aging Whois protocol.

🚀

RESTful API

Uses standard HTTP methods, making it highly intuitive for developers.

📦

JSON Data

Provides structured JSON format for easy parsing and data processing.

🔗

Bootstrap Hub

Serves as an integrated redirect hub to authoritative RDAP servers worldwide.

📡 API Usage Guide

Query global internet resource information via https://bootstrap.rdap.kr/.

Real-time Redirect Service

  • GET /domain/{name} e.g., https://bootstrap.rdap.kr/domain/google.com
  • GET /ip/{address} e.g., https://bootstrap.rdap.kr/ip/8.8.8.8
  • GET /autnum/{number} e.g., https://bootstrap.rdap.kr/autnum/15169
  • GET /entity/{handle} e.g., https://bootstrap.rdap.kr/entity/IPADM11-ARIN
