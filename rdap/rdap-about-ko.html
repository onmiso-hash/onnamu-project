RDAP란 무엇인가요?

RDAP (Registration Data Access Protocol)는 기존 Whois 서비스의 여러 기술적 한계를 극복하기 위해 IETF에서 정의한 차세대 인터넷 주소 정보 조회 프로토콜입니다.

🚀

RESTful API

표준 HTTP 방식을 사용하여 개발자가 연동하기 매우 직관적입니다.

📦

JSON 데이터

정형화된 JSON 형식을 제공하여 파싱과 데이터 처리가 쉽습니다.

🔗

부트스트랩 허브

전 세계 RDAP 서버로 연결해주는 통합 리다이렉트 기능을 제공합니다.

RDAP와 WHOIS, 무엇이 다른가요?

WHOIS 기존 RDAP 현재 표준
응답 형식 정형화되지 않은 평문 텍스트 표준 JSON — 기계가 바로 읽고 파싱 가능
국제 표준 사실상 표준 없이 레지스트리마다 형식이 제각각 IETF 표준(STD 95), ICANN 권고 프로토콜
보안 · 개인정보 접근 제어 없이 전체 정보를 그대로 노출 권한에 따라 응답 항목을 다르게 줄 수 있음
다국어 지원 ASCII 위주, 다국어 처리 제한적 국제화된 문자 집합을 표준으로 지원

📡 API 호출 가이드

https://bootstrap.rdap.kr/을 통해 전 세계 인터넷 자원 정보를 조회할 수 있습니다.

실시간 리다이렉트 (Redirect Service)

  • GET /domain/{name} 예: https://bootstrap.rdap.kr/domain/google.com
  • GET /ip/{address} 예: https://bootstrap.rdap.kr/ip/8.8.8.8
  • GET /autnum/{number} 예: https://bootstrap.rdap.kr/autnum/15169
  • GET /entity/{handle} 예: https://bootstrap.rdap.kr/entity/IPADM11-ARIN (ARIN 태그 분석 후 리다이렉트)

부트스트랩 원본 데이터 (Raw JSON)

IANA에서 동기화된 각 카테고리별 원본 데이터를 제공합니다.

DNS (Domain) IPv4 IPv6 ASN Object Tags (Entity)

CLI 테스트 (cURL)

# 리다이렉트 흐름 확인하기
curl -v https://bootstrap.rdap.kr/domain/nic.car

# 최종 결과 데이터 바로 받기
curl -L https://bootstrap.rdap.kr/ip/211.231.99.17

근거 표준 (RFC)

RDAP은 IETF STD 95로 표준화되어 있으며, 아래 RFC 문서들이 그 근거입니다.

  • RFC 7480 — HTTP Usage in the Registration Data Access Protocol (RDAP)
  • RFC 7481 — Security Services in the Registration Data Access Protocol (RDAP)
  • RFC 9082 — Registration Data Access Protocol (RDAP) Query Format
  • RFC 9083 — JSON Responses for the Registration Data Access Protocol (RDAP)
  • RFC 9224 — Finding the Authoritative Registration Data Access Protocol (RDAP) Service
